01 — Architektur

Intelligentes Backend, einfache Terminals

Das Lesegerät liest eine Karte und sendet ein rohes Ereignis. Alle Regeln — wem die Karte gehört, Ein- vs. Ausstempeln, Duplikaterkennung — leben im Backend, wo sie geprüft, geändert und getestet werden können, ohne Hardware anzufassen.

02 — Integrität

Unveränderliches Protokoll

Jeder Scan wird einmalig geschrieben und nie verändert. Korrekturen sind neue Einträge mit Autor und Grund. Sie haben ein vollständiges, manipulationssicheres Anwesenheitsprotokoll ab dem ersten Tag.

03 — Datenschutz

Zugangsdaten als HMAC-Fingerabdruck

Rohe Karten-UIDs werden nie gespeichert. Das System hält nur einen HMAC-Fingerabdruck, der von einem rotierbaren Secret abgeleitet wird. Eine gestohlene Datenbank kann nicht aufdecken, welche Karte zu welcher Person gehört.

04 — Datensouveränität

On-Premise, keine Cloud erforderlich

Betrieb aus einem einzigen Docker-Image auf Ihrem eigenen Server. Keine externen Accounts, kein Abo, keine Daten außer Haus. Funktioniert auch im Intranet ohne Internetzugang. Ihre Daten. Ihre Hardware. Ihre Regeln.

Ein Terminal, das überall passt

Ein kompaktes, wandmontierbares NFC-Lesegerät, das mit Ihrem lokalen Netzwerk verbunden ist. Mitarbeiter tippen eine Karte, einen Tag oder Aufkleber an — das Ergebnis erscheint innerhalb einer Sekunde auf dem Display. Keine App. Kein Login. Keine Reibung.

  • NFC-Tap — kontaktlose Karten, Tags und Aufkleber
  • Sofortige Rückmeldung — Name, Uhrzeit, Ein- oder Ausstempeln
  • Nur lokales Netzwerk — kein Internet am Terminal erforderlich
  • Wandmontage — Befestigungsmaterial inklusive
  • Dauerbetrieb — USB-C-Speisung, automatischer Neustart bei Ausfall
  • Crispy Feedback — kurzer Bestätigungston für jeden akzeptierten Scan
  • Privacy by Design — rohe Karten-UID wird nie gespeichert

Gebaut auf ehrlichem Engineering

  • Das Terminal ist ein einfaches Edge-Gerät. Es liest Hardware, setzt Zeitstempel und sendet. Jede Geschäftsregel lebt im Backend — dort wo Entscheidungen hingehören, wo sie getestet werden können und wo sie eine Spur hinterlassen.
  • Ein Ereignis ist permanent, sobald es geschrieben ist. Das Anwesenheits-Ledger ist append-only. Das ist keine Einschränkung, sondern eine Garantie: Sie können immer exakt rekonstruieren, was wann und warum passiert ist.
  • Zugangsdaten sind Kennungen, keine Geheimnisse. NFC-Karten können geklont werden. Deshalb speichern wir nie die rohe UID, sondern nur einen HMAC-Fingerabdruck, der an ein Secret geknüpft ist, das Sie kontrollieren. Der Fingerabdruck ist ohne den Schlüssel wertlos.
  • Ihre Daten verlassen das Gebäude nicht. CrispyClocks ist von Tag eins für On-Premise-Betrieb ausgelegt. DSGVO-Konformität ist eine Architektureigenschaft, kein Häkchen in einer Checkliste.
